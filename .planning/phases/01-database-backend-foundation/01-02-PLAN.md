> **POST-EXECUTION AMENDMENT (2026-06-08):** This plan was executed as written, but CR-01 code review found a route-accumulation bug in the `create_stream_router(cache)` approach. The implementation was subsequently updated: `create_stream_router` was removed; `stream_router` is now a module-level APIRouter registered via `app.include_router(stream_router)` at module level in `main.py`; the SSE handler reads `price_cache` from `request.app.state.price_cache`. Instructions in this plan that reference `create_stream_router` or `include_router` inside lifespan are **superseded**. See `01-02-SUMMARY.md`, `01-PATTERNS.md`, and `01-REVIEW.md` (CR-01) for the current correct pattern.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → GET /api/health | Public endpoint; returns static JSON; no input processing |
| Lifespan → app.state | Internal — PriceCache and MarketDataSource stored on app.state, never exposed to request parameters |
| Backend → Market data source | Internal — simulator or Massive client started with a hardcoded ticker list from SEED_PRICES |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | GET /api/health | accept | Returns {"status": "ok"} only — no server internals, no stack traces, no version numbers |
| T-02-02 | Tampering | app.state.price_cache / app.state.market_source | accept | app.state is internal to the Python process; not accessible to end users; acceptable for single-container single-user app |
| T-02-03 | Denial of Service | lifespan startup failure (DB or market source crash) | mitigate | init_db() is idempotent (tested); market source start failure raises an exception that uvicorn reports; no silent failure path |
| T-02-04 | Spoofing | SSE router double-registration | mitigate | create_stream_router(cache) called exactly once inside lifespan before yield; no module-level call; prevents duplicate route registration |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase; all imports are fastapi, stdlib contextlib/logging, and existing project modules |
</threat_model>
