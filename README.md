# FinAlly — AI Trading Workstation

FinAlly is an AI-powered trading terminal with live-streaming market data, a simulated portfolio, and an LLM chat assistant that can analyze positions and execute trades on your behalf.

This repository is currently in the **planning and tooling stage**. No application code has been written yet.

## Project Specification

See [`planning/PLAN.md`](planning/PLAN.md) for the full project specification, including architecture, API design, database schema, and feature scope.

## Tooling

**`independent-reviewer/`** — A local Claude Code plugin that reviews all changes since the last commit and writes findings to `planning/REVIEW.md`.
